# Contributing to Board Game Recommendations System

This is an academic project for a thesis at Pontificia Universidad Javeriana Cali.

## Development Setup

### Prerequisites

- Python 3.11+
- Node.js 18+
- PostgreSQL 15+
- Docker and Docker Compose (optional)

### Getting Started

1. Clone the repository
2. Follow the installation instructions in the [README.md](README.md)
3. Create a branch for your changes
4. Make your changes
5. Run tests and linters
6. Submit a pull request

## Code Style

### Backend (Python)
- Follow PEP 8 guidelines
- Use type hints
- Document functions with docstrings
- Run `black` for formatting
- Run `flake8` for linting

### Frontend (TypeScript/React)
- Follow TypeScript best practices
- Use functional components with hooks
- Use Material-UI components
- Run `npm run lint` for linting

## Testing

### Backend
```bash
cd backend
pytest
```

### Frontend
```bash
cd frontend
npm test
```
